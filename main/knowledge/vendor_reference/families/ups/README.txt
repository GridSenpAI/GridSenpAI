UPS Family Pack v2.0.0

This pack is intended to be dropped into GridSenpAI as the UPS vendor-reference family.

Characteristics:
- Only models with sufficient official source-backed static specification support were kept.
- Unsupported brands/models were omitted rather than padded with weak records.
- Fixed specs were backfilled only when supported by official manufacturer PDFs or official manufacturer product pages.
- Project-specific fields remain null by design and should trigger applicant intake.

Omitted in this pass:
- Schneider Electric / APC UPS models (insufficient direct static spec extraction from confirmed official source set for this library standard)
- Vertiv Liebert GXT5
- ABB UPS5000
- Additional Mitsubishi legacy lines outside the 9900 family

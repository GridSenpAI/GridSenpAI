Transformer Family Pack v1.0.0

This pack is intended to be dropped into GridSenpAI as the Transformer vendor-reference family.

Characteristics:
- Product-line records are used instead of fake exact-model records because transformer manufacturers often publish configurable line documentation rather than one canonical exact model.
- Only source-backed static product-line fields were populated.
- Project-specific fields remain null by design and should trigger applicant intake.
- This pack emphasizes data-center-relevant dry-type and cast-resin transformer lines with official documentation support.

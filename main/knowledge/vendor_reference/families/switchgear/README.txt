Switchgear Family Pack v2.0.0

This pack is intended to be dropped into GridSenpAI as the Switchgear vendor-reference family.

Characteristics:
- Product-line records are used instead of fake exact-model records because switchgear vendors often publish configurable line documentation rather than one canonical exact model.
- Only source-backed static product-line fields were populated.
- Project-specific fields remain null by design and should trigger applicant intake.
- This pack uses the reduced 17-record list across Eaton, Siemens, Schneider Electric, and ABB.


Hardening pass v3: additional source-supported static fields were backfilled where the official source set clearly supported them.
